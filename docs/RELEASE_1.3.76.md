# v1.3.76：YuE2 INT8 与参考音频

已于 2026-10-11 21:24:44（Asia/Shanghai）正式发布并设为 Latest。

## 变化

- YuE2 从原版 BF16 加载器升级为固定 Comfy INT8 推理库。官方原版模型 revision 没变，但权重格式和工作流不同，需要同时升级应用与独立资源。
- 保留纯音乐／带歌词歌曲的简单入口，增加可折叠的参考音频选项。参考旋律可用于新风格和歌词的改编；导入副本留在本机，原文件不变，支持参数复用。
- 纯音乐自动完成生成、去人声、旋律提取、重生成与再次去人声。使用独立进程，完成和取消后释放模型。
- YuE2 时长上限可设 8–600 秒，达到时长或上下文上限时如实提示；模型可提前结束。界面说明 CUDA 13、BF16、显存／内存和长片段需求。
- 新资源 `2026.10.11-yue2-int8` 使用 Python 3.13.12、匹配的 torch/torchaudio 2.11.0。下载约 6.57 GiB、安装约 8.54 GiB，8 分卷 + JSON，仍从独立资源 Release 下载，不进入应用包。
- ACE-Step 默认引擎、MusicGen、已有作品与旧资源保持兼容，旧 YuE2 权重不覆盖。

## 本地验证

RTX 3080 Ti 12 GiB 上通过 45 秒歌曲、10 秒自动纯音乐、参考旋律改编为 14 秒歌曲；PyTorch 显存峰值分别 4.101、3.935、3.855 GiB。通过剪辑、收藏、取消、EOF 关闭和重启保留。MP3、FLAC、M4A、OGG 导入转换及原文件保留通过；便携 Python 环境 9 项测试全部通过；基础环境为 7 项通过、2 项解码测试跳过。

前端检查 299 项、外观守卫、生产构建通过；Rust 547 项通过、5 项 opt-in 忽略，Clippy 全目标通过。真实 Tauri 四种外观覆盖参考区域、对话框、720 px、导航与刷新。隔离原生应用还通过 ACE-Step 12 秒生成、播放、剪辑与导出，重启后作品及参考音频保留。独立资源 8 分卷和清单已公开，GitHub digest 与匿名下载字节比对通过，原生应用成功读取公开清单。更多证据见 [升级记录](YUE2_261011_UPGRADE.md)。未验证完整 600 秒或逐字演唱准确率，未做主观音质评分。

## 手动导入

在音频工作台“环境与下载”选 **YuE2 INT8 → 导入离线资源**，选择同时包含以下清单及全部同前缀 `.zip.part` 分卷的文件夹：

`music-workbench-2026.10.11-yue2-int8-windows-x64-cu130.json`

无需手动解压，原始整合包权重目录不能直接导入。需要 RTX 30 系或同等 BF16 能力及 CUDA 13.0 兼容驱动。原有歌曲、参考原文件及旧版资源保留。
