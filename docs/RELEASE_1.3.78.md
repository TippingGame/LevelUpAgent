# v1.3.78：图片预览适配窗口与复制图片

## 变化

- 创作空间打开或切换图片时自动适配窗口，完整显示大图和长图，为导航、缩放工具条留出空间；小图保留原始大小。
- 适配模式随窗口尺寸变化重新计算，手动缩放、拖动、1:1 和适应窗口操作继续可用；超宽图允许低于 5% 的缩放比例。
- 图片预览右上角新增复制图片按钮，预览区和作品缩略图的右键菜单新增复制图片。支持键盘操作与复制中、成功、失败反馈。
- 复制完整分辨率的图片像素，JPEG/WebP 转为兼容剪贴板的 PNG，透明 PNG 保留透明度。
- 应用版本升级到 1.3.78，音频及 3D 独立资源继续复用。

## 发布验证

本地锁定依赖安装、301 项前端测试、外观守卫、生产构建、Rust 格式检查、549 项 Rust 测试及全目标 Clippy 均通过；5 项 opt-in Rust 测试按默认规则忽略。3D Python 测试 14 项通过、2 项平台测试跳过；音频 Python 测试 7 项通过、2 项便携解码器测试跳过。

浏览器和隔离 Tauri 原生窗口均完成系统深浅色 × Armor Mode 开关四种组合检查，保留截图。720 × 560 和 1440 × 920 视口、首次打开、重开、前后切换、窗口缩放、手动 1:1、右键菜单边缘定位与 Escape/Enter 操作通过。2000 × 1200 PNG、1200 × 2400 JPEG、200 × 100 WebP、20000 × 200 超宽图均完整显示；Windows 系统剪贴板读取确认复制后的分辨率与原图相同。浏览器确认透明度保留、读取失败提示和重试恢复。
