# 功能总览

2026-09-18，根据前端入口、Tauri 注册命令、Rust 执行路径和测试重新核对。发布基线 `1.0.56`，本轮改进尚未发布。
桌面运行以 React 19、Tauri 2、Rust 和 SQLite 为基础；浏览器预览只模拟可在前端展示的行为。

## Agent 与会话

| 功能 | 当前行为 | 实现与验证 |
| --- | --- | --- |
| 项目与会话 | 打开目录、临时工作区、项目分组/折叠/隐藏，会话新建、重命名、置顶、删除 | `App.tsx`、`storage.ts`、数据库测试 |
| 历史目录 | 桌面首次取 100 条摘要，游标加载更早记录；选中会话才加载正文 | `database/conversations.rs`；205 会话分页回归 |
| 搜索 | 搜索标题、工作区和非内部的用户/助手正文；中文、字面 `%`/`_` 均支持 | SQLite 查询、目录合并测试；尚无 FTS 索引 |
| 快捷导航 | 聊天 `Ctrl/Cmd+K`、搜索按钮，方向键/Enter/Escape，命令和会话入口 | `CommandPalette.tsx`；浏览器验收 |
| 独立草稿 | 文本与最多 12 个附件引用按会话保存；切换、重启恢复，失败可重试 | `composerDrafts.ts`、SQLite `composer_drafts`；存储失败与竞态测试 |
| 长会话 | Markdown、代码复制、工具组折叠；初始展示最近 40 个块，逐批加载早期消息 | `MarkdownRenderer.tsx`、会话滚动测试 |
| 流式输出 | SSE、停止、重连状态、失败保留部分输出；不在已输出后静默换模型 | 四协议 HTTP fixtures、`threadExecution.ts` |
| 模式与权限 | Agent / Plan / Chat / Goal；request / agent / full；主机重复校验 | `harness/policy.rs`、模式越权回归 |
| 运行中输入 | 普通追加、`/follow-up`、`/next-turn`、`/steer`；逐项注入或取消 | SQLite queue 与事务竞态测试 |
| 长任务 | Goal 状态、用量、暂停/恢复、完成审计、连续阻塞判断 | `database.rs`、Harness；不是定时调度器 |
| 恢复 | 重启暂停活动 Goal，中断旧 operation，保留审批，结果不明工具人工对账 | 数据库恢复测试；不自动重放副作用 |
| 分支 | 从当前会话建立独立消息 ID 的副本和 session lineage | `harness_fork_session`、`forkActiveThread`；不创建主任务 Git worktree |
| 导入导出 | JSON 与可读 Markdown，对话原始结构和附件元数据 | `conversationExport.ts`；附件字节不是会话导出的完整备份 |
| 通知 | 完成提示、未读会话数、任务栏标记、跳转结果 | `taskCompletion.ts`、`taskbarBadge.ts` |

详细流程与恢复限制见 [Agent 工作流](AGENT_WORKFLOWS.md)。浏览器回退最多保存最近 80 个会话；桌面 SQLite 目录没有原先 200 条的入口限制。

## 模型与上下文

| 功能 | 当前行为 | 边界 |
| --- | --- | --- |
| 连接 | 多连接增删改、复制、排序、检测、模型切换、思考档位 | 复制连接不会复制密钥；媒体连接可没有文字模型 |
| 协议 | Responses、Chat Completions、Messages、GenerateContent；OpenCode Go 模型族路由 | 本地模拟 HTTP 测试不代表全部真实厂商在线成功 |
| 模型发现 | 先标准目录，再按配置或返回模型判断是否探测 Gemini；合并已确认路由 | 不为所有平台密钥盲目探测 Gemini |
| 故障转移 | 首选连接、最多 7 个备用连接、冷却、延迟和健康统计 | 400/422、用户取消或已经输出的请求不切换 |
| Instructions | 应用自定义指令；Agent/Plan/Goal 自动读工作区根 `AGENTS.override.md` 或 `AGENTS.md` | 最大 32 KiB UTF-8，拒绝 symlink；只读选定根目录，未实现嵌套目录继承 |
| 上下文治理 | Token 估算、工具调用/结果原子组、确定性 checkpoint、可见省略信息 | 固定预算是估算，不是每个模型精确 tokenizer；完整历史仍在 SQLite |
| 附件 | 选择、拖入、粘贴和消息中的本地路径；图片、文本、PDF、Office 提取和原文件引用 | 任意格式可保存，但未解码格式不会冒充已理解；复制到托管目录与工作区 |
| 诊断 | 余额/用量、模型请求日志、延迟、Token、request-id、日志目录 | Provider 请求日志不保存正文；会话和 Harness 账本包含任务内容 |

## 创作与个性化

| 功能域 | 已有功能 | 状态与限制 |
| --- | --- | --- |
| 图片 | 多提示并发、参考图及顺序、比例/质量/格式/数量、生成/编辑、结果预览、保存与删除 | 显式蒙版需要支持 edits 的路由；不是所有模型都支持所有参数 |
| 视频 | 文生、首尾帧/参考图、参数能力匹配、独立轮询、下载进度、失败重试、重启恢复 | 已提交任务由上游执行；本地停止不保证取消上游计费 |
| 语音 | 模型与音色、生成、播放、本地历史/导出 | 以配置服务支持为准 |
| 写作 | 项目/文稿、流式补全、选区改写、接受/拒绝、设定与关系、参考库、Partner/AI Lead Goal、快照 | 独立无工具 chat 链路；16 MiB 项目上限 |
| 剧情 | 类型化节点、变量与条件/效果 DSL、检查和试玩、JSON/Markdown/Yarn 导出 | 不执行任意脚本 |
| 星图 | 8 类节点、类型化 DAG、拓扑层并行、局部运行、蓝图、画板/蒙版、撤销重做、导入导出 | 浏览器本地保存；无服务器协作、无限运行或任意插件执行 |
| Armor | 全局执行提示开关、5 个 profile、8 个可选提示模块、写作强度和媒体编译 | 不改变主机权限，不保证模型能力或服务可用性 |
| 摇光残影 | 桌面显示、缩放与定位、陪伴、日程/任务、签到/学习、知识与记忆、孵化/导入、完整备份恢复 | 平台窗口行为和付费孵化需目标机器验证；不是通用后台调度 |
| 主题与布局 | 包安装/切换/卸载、严格作用域 CSS、声明式布局、AI 主题生成 | 不允许主题 JS、远程资源或凭据访问 |
| 桌面设置 | 中英文、明暗、侧栏/检查器/输入区尺寸、开机启动、更新检查 | 更新需要正式签名配置；本次没有执行真实升级 |

媒体、写作和星图首次访问时才加载，访问后保持挂载，保留后台作业和未保存的交互状态。Armor 和陪伴管理弹窗也按需加载。

## 审阅结论

本次修复模式权限绕过、全历史重写、会话目录硬截断、草稿串会话与首屏加载过重等问题，并补齐快捷检索和项目指令。
完整主任务 worktree 管理、交互式 PTY、持久化定时任务、SSH/云任务仍未实现；不以子 Agent worktree 或后台进程替代这些承诺。
实测范围见 [性能](PERFORMANCE.md) 和 [审阅记录](AGENT_REVIEW_2026-09.md)。
