# v1.4.85：MiniMax 视频模型识别与 Grok 语音修复

- 创作空间识别带前缀的 MiniMax H3 / Seedance 视频模型，列表、请求和历史保留完整模型 ID。
- 1080P、1K、2K 等固定清晰度分别保留，避免模型档位被错误替换；兼容中转连接使用对应视频请求流程。
- Grok 语音改用原生 `/v1/tts` 接口，支持 MP3 / WAV、默认 eve 或自定义声音，兼容二进制和 JSON base64 音频响应，并明确报告无效音频和服务端错误。
- 语音界面按 Grok 能力显示格式和参数，切换模型时清理不兼容选项；其他语音模型保留原有设置能力。
- 应用版本为 1.4.85；音频及 3D 独立资源版本保持不变并继续复用。

## 验证

- 冻结依赖安装、308 项前端测试、外观检查、生产前端构建和 Rust 格式检查通过。
- Rust 全量 589 项通过（5 项忽略），全目标 Clippy 零警告。
- 3D Python 21 项（3 项平台相关跳过）、音频 Python 9 项（2 项需要便携运行环境而跳过）检查通过。
- Grok 语音浏览器回归覆盖系统浅色／深色 × 破甲开／关、1200px／720px、模型切换、重载和提交参数；使用模拟 IPC 与凭据，不代表真实供应商在线生成测试。
- 同步修正旧破甲回归断言，使其允许 Grok 不发送不支持的演绎要求；普通语音仍直接使用用户输入。
