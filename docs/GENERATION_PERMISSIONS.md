# 孵化与主题生成的权限和完成流程

任务类型与权限级别分开处理。选择“完全权限”后，桌宠孵化和主题生成使用普通 Agent 的工具目录与权限策略；不能因为任务带有 hatch 标记或主题初始化标记，再隐藏文件、命令、Skill、浏览器或已配置的外部工具。

## 权限来源

桌面任务在 `harness_start` 时记录权限。后续 Provider 轮次、工具执行和审批恢复都读取该任务持久化的权限，不能通过工具参数中的 `permissionLevel` 或 `allowOutsideWorkspace` 自行升级。

| 行为 | 完全权限 | 询问 / Agent 权限 |
| --- | --- | --- |
| 工具目录 | 正常工具目录，仍受聊天/规划等模式约束 | 保留现有任务专用工具范围 |
| 文件和目录 | 可使用工作区外绝对路径 | 工作区边界及用户附件授权规则生效 |
| 命令 | 辅助命令、shell 组合、显式 workdir 按通用策略执行 | 保留现有审批及孵化脚本规则 |
| 查询孵化进度后的操作 | 可读取文件、排查问题、继续生成等 | 无效操作返回有限次数的纠错反馈 |
| 主题准备步骤 | 允许读取、暂存、修改和命令处理 | 保留直接写入目标文件的精简流程 |
| 产物验收 | 必须通过 | 必须通过 |

完全权限不会把不存在的工具变成可用工具，也不会取消规划模式的只读约束或操作系统本身的权限。

## 桌宠孵化

1. 应用准备运行目录、加载内置 Skill 和首次任务状态。
2. 模型选择待生成的 `hatchJobId`；适配器装载该任务的提示词及参考图，无需模型另行读取文件。
3. 生图结果记录到持久化来源账本，再通过 `record_imagegen_result.py` 归档。内置直接脚本调用仍使用已检查的 Python 解释器和图片来源校验。
4. 完全权限下的其他命令进入普通执行器，不因“不是白名单脚本”或“刚查询过状态”而被阻断。
5. 继续生成、镜像、修复、拼装和打包。导入时保留原有桌宠包验收，已有图片不因辅助操作被删除。

## 主题生成

1. 应用创建固定产物路径，附加规范和已有视觉素材。
2. 完全权限下可按需要读取资料、使用工具和准备中间文件。不存在最终主题文件不代表这些步骤失败。
3. 写入、编辑或命令等可能产生产物的操作完成后，如果目标文件已存在，应用验证该目标；普通只读调用不触发产物缺失错误。
4. 目标首次通过校验后结束并导入；审批恢复时也先验证已写入目标，避免重复生成。
5. CSS 作用域、禁用可执行内容、资源内嵌、布局 schema 和包大小限制属于主题运行时格式契约，不受生成 Agent 的完全权限影响。

验证应同时覆盖完全权限、受限权限、审批恢复、工作区外读取/写入、非默认命令目录、主题中间步骤以及最终产物验收。
