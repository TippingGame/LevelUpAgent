# 创作空间能力审计：LevelUpAgent × Image Studio

> 记录日期：2026-08-06 · LevelUpAgent `1.0.17`

这份审计把 LevelUpAgent 的创作空间与本地参考项目 Image Studio 做一次面向产品决策的对照。目标不是复制某个界面，而是优先补齐创作者每天都会用到、且能和星图蓝图形成闭环的能力。

## 能力映射

| 创作任务 | Image Studio 的做法 | LevelUpAgent 当前做法 | 结论 |
| --- | --- | --- | --- |
| 文生图 / 图生图 | 单工作区生成表单、参考图 | 图片标准能力 + 星图图像节点 | 已覆盖；星图可以把提示词、图像、视频和语音串成 DAG |
| 扩图 | 画布边缘扩展、方向和比例控制 | 画板与蒙版节点，10/25/50% 四周扩边，输出透明 PNG | 已覆盖；保留“源图 + 蒙版”后端契约 |
| 局部重绘 | 涂抹区域后编辑 | 画板笔刷、擦除、撤销/重做和独立 mask 输入 | 已覆盖；避免把标注层误当成原图 |
| 图片标注 | 矩形、箭头、自由线、文字 | 画板节点支持笔刷、标签和蒙版 | 部分覆盖；矩形/箭头/文字标注列入下一阶段 |
| 历史与复用 | 历史搜索、日期/模式筛选、参数复用、raw response | 全局创作历史，结果可在预览节点复用 | 核心链路已覆盖；搜索和参数快照仍需增强 |
| 参数管理 | seed、negative prompt、style chips、预设 | 模型路线、比例、质量、格式、数量 | 当前参数足够跑通流程；seed/negative/style 是高价值补齐项 |
| 前后对比 | before/after、旋转、翻转、裁剪 | GPU 预览、缩放、平移、适应窗口和实际大小 | 预览性能已优先修复；对比/裁剪列入下一阶段 |
| 批量创作 | 批量目录、批量 img2img | 星图并行分支、每条数量 | 已有编排基础；批量文件夹导入仍待产品化 |
| 工作流复用 | 单 workspace 历史上下文 | 类型化节点、框选保存蓝图、内置蓝图、导入/导出 | LevelUpAgent 的差异化优势 |

## 本轮直接修正

- 端口视觉圆点与实际命中区分离：可见 Handle 为 10px，外围透明区域承担约 26px 命中，连线端点不再落在透明盒边缘。
- 端口支持点击-点击和拖动两种连线方式，支持重连；不兼容连接会显示中英文原因。
- 节点拖动取消 16px 网格吸附，位置按指针连续更新。
- 图片预览改为 `requestAnimationFrame` 驱动的 GPU `transform`，拖动期间不再每帧触发 React 状态和布局。
- 画板图片层、标注层和蒙版层分离，笔刷使用增量绘制；画布支持平移、缩放、适应窗口和实际大小。
- 交互期间隐藏 MiniMap、降低阴影/过渡并限制自动保存频率，减少高刷新率下的合成压力。

## 下一阶段优先级

### P0：让一次创作更容易复现

1. **参数快照**：保存 seed、negative prompt、模型路线、比例、质量和参考图摘要；历史卡片一键“使用参数重做”。
2. **历史检索**：按关键词、日期、模式（生成/编辑/扩图/重绘）筛选，保留失败任务和重试入口。
3. **蓝图输入契约**：在蓝图卡片显示输入/输出端口，插入时提供冲突提示和可选自动布局。

### P1：让图片修改更精确

1. 矩形、箭头、自由线和文字标注，标注层可独立隐藏、删除和导出。
2. before/after 对比、旋转、翻转和非破坏裁剪。
3. 批量目录导入与逐图失败重试，复用同一套参数和蒙版策略。

### P2：让社区扩展更容易

1. 蓝图版本、缩略图、作者和兼容能力声明。
2. 蓝图导入前预览依赖、缺失模型和权限范围。
3. 可选的社区蓝图目录；默认仍保持本地优先和显式导入。

## 有意保留的取舍

- 不复制 ComfyUI 的无限节点菜单和大量插件配置；默认只展示四项标准能力与少量创作工具，降低首次使用成本。
- 不把输出结果直接序列化进蓝图；蓝图只保存可复现的结构、参数和提示词，避免私有素材泄漏与文件膨胀。
- 不用“看起来像蒙版”的前端透明图代替真实 mask；后端会严格校验 PNG、源图和路由能力。
- 不在拖动期间实时更新 React 布局状态；交互结束后再提交语义状态，保证 120Hz/144Hz 屏幕上的连续性。
