# 星图本地工具模板

本地工具节点会在桌面应用的工作区中执行一条命令。Windows 使用 PowerShell，命令最长运行 120 秒；命令的标准输出会成为节点的文本输出，并可以继续连到下一个节点。

## 从模板开始

1. 添加“本地工具”节点，在“工具模板”下拉框中选择“内置示例”里的“运行脚本（内置）”。“我的模板”里的项目是你保存过的副本。
2. 修改“模板名称”“命令模板”和“参数模板”。命令中写 `{{args}}`，运行时才会把参数模板的结果放进去。
3. 输入字段中的 `id` 会成为变量名。例如字段 `input` 可以在命令中写成 `{{field:input}}`，也可以把上游节点连接到这个输入端口。
4. “输入”区域里的值是这个节点的备用值：有上游连接时使用上游文本，否则使用这里填写的值。
5. 点击“保存为可复用模板”。内置模板会自动保存为带“（副本）”后缀的新模板；同名模板会增加序号，避免下拉框里出现两个无法区分的选项。

以后在另一个本地工具节点的“我的模板”中选择它即可复用。修改自定义模板后再次保存会更新同一个模板；已经使用它的其他节点保留各自的配置，重新选择模板才能载入修改。输入框的本次值随节点保存，不会自动变成模板的默认值。

内置“运行脚本”只是连通性示例，默认命令输出 `tool ready`，不会自动执行 Python 脚本，也不会自动使用输入。要使用输入，必须在命令里放入 `{{args}}`、`{{input}}` 或 `{{field:id}}`。

旧节点会保留原先的命令。若仍显示 `python -c "print('tool ready')"`，重新选择“运行脚本（内置）”可载入新版示例；选择模板会重置该节点的命令、字段和输入值。

## 一个可以直接试的例子

把内置模板改成：

- 模板名称：`文本回显`
- 命令模板：`echo "{{args}}"`
- 参数模板：`{{field:input}}`
- 输入字段：保留 `input`，在下面的输入框填写 `hello`
- 输出字段：保留“标准输出”，来源使用 `{{stdout}}`

点击“运行到这里”后，节点输出就是 `hello`。也可以把输入节点连到 `input` 端口，运行时就会使用上游文本。

如果命令输出 JSON，可以新增一个输出字段，名称和 ID 都填 `summary`，类型选 `text`，来源填 `{{json:summary}}`。例如 PowerShell 命令模板可以写：

```powershell
$value = "{{args}}"; @{summary=$value} | ConvertTo-Json -Compress
```

参数模板仍填 `{{field:input}}`，输入 `hello` 后，`summary` 输出为 `hello`。输出来源中的 `{{json}}` 表示整个 JSON 对象，`{{field:id}}` 表示输入字段原值。

模板变量按字面替换，不会自动转义 shell 引号。以上回显示例适合普通短文本；脚本接收复杂内容时，需要根据 PowerShell 的语法处理引号和换行。

## 常见情况

- 下拉框里分成“内置示例”和“我的模板”，解决同名模板难以区分的问题；自定义模板名称重复时还会显示序号。
- 命令返回非零退出码时节点会报错，并显示 stderr；成功时下游只接收 stdout。
- 涉及写文件、删除文件、联网或其他高风险操作的命令可能需要审批。需要在会话里处理审批时，使用“会话执行”节点更合适；本地工具模板适合可重复的安全命令。
- 模板保存在当前应用配置的本地存储中，重启应用后仍然可用；它不会自动复制到其他电脑。
