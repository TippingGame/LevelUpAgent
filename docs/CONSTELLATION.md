# 星图（Constellation）

星图是 LevelUpAgent 创作空间的可视化编排界面。它把现有的写作、图像、视频和语音四项标准能力组合成可执行的有向无环图，同时加入画板、标注、蒙版、扩图和可复用蓝图。

## 产品原则

- **先完成作品，再暴露复杂度**：默认星图只有“提示词 → 图像 → 作品预览”，新用户不需要先理解工作流术语。
- **端口即契约**：文本、图像、视频、语音和媒体联合类型在连接时校验；重复连接、单输入冲突和环路在落图前拒绝。
- **局部流程可复用**：框选任意节点后可保存为个人蓝图；仅保存内部连线，实例化时为所有节点和连线生成新 ID。
- **流程和运行解耦**：图结构、参数和提示词自动保存；节点输出可恢复，但个人蓝图主动剔除运行结果、私有素材和临时状态。
- **失败不阻塞无关分支**：执行计划按拓扑层并行运行；上游失败只阻断其后代，其余分支继续完成。
- **紧凑界面不牺牲能力**：桌面宽度展示节点库；中窄屏默认收起两侧面板，通过画布内按钮以抽屉方式访问。

## 节点模型

| 节点 | 输入 | 输出 | 作用 |
| --- | --- | --- | --- |
| 提示词 | — | `text` | 一次编写并分发创作指令 |
| 灵感写作 | `text` 任务、可多路 `text` 上下文 | `text` | 扩写、改写、脚本和提示词增强 |
| 图像生成 | `text`、可多路 `image`、可选 `image` 蒙版 | `image` | 生成、编辑、扩图和局部重绘 |
| 视频生成 | `text`、可多路 `image` | `video` | 文生视频、首帧或参考图生视频 |
| 语音生成 | `text` | `audio` | 文案转语音 |
| 画板与蒙版 | 可选 `image` | `image` 标注图、可选 `image` 蒙版 | 标签、笔刷、擦除、扩边、撤销和重做 |
| 作品预览 | `media` | — | 预览文本、图像、视频或语音结果 |
| 便签 | — | — | 为流程记录意图和协作说明 |

`media` 是输出预览使用的联合输入类型；其他端口保持严格类型。图结构必须是 DAG，以确保运行顺序确定且可并行。

## 蓝图协议

星图和蓝图当前使用 `schemaVersion: 1`。导入过程会：

1. 限制节点和连线数量；
2. 修复重复节点或连线 ID；
3. 丢弃悬空、类型不兼容、重复、单输入冲突和成环连线；
4. 清除运行中、排队中和错误等瞬态状态；
5. 对蓝图额外移除输出、托管参考素材、画板源图和蒙版附件。

个人蓝图保存在 `levelup-agent.constellation-blueprints.v1`，当前星图保存在 `levelup-agent.constellation.v1`。导出的 `.levelup-constellation.json` 同时包含完整星图和个人蓝图库，导入时采用防御性规范化。

内置蓝图：

- 灵感成片
- 有声故事卡
- 智能扩图工作台
- 蒙版局部重绘

## 执行模型

运行前先计算目标节点的依赖闭包，再使用 Kahn 拓扑排序生成执行波次。同一波次用 `Promise.all` 并行：

```text
提示词 ─→ 写作 ─┬→ 图像 ─→ 视频 ─→ 预览
                └→ 语音 ─────────→ 预览
```

- 写作节点复用 `agentTurnStream`，支持流式节点预览和取消。
- 图像、视频、语音节点复用 `generateMedia`，结果继续进入全局创作历史。
- “运行到这里”只运行目标及其祖先。
- 停止后不再把晚到结果写回当前运行；已经提交的媒体任务仍可在后台完成并保存。
- 创作空间侧栏显示媒体工作台与星图的合并后台任务数。

## 画板、扩图与蒙版

画板在原始像素坐标中保存笔画和标签，支持 10%、25%、50% 四周扩边。改变扩边比例时，现有笔画和标签会随原图偏移，不会被静默清空。

输出包括：

- 带透明扩边和可选标签的 PNG 图像；
- OpenAI 图片编辑语义的透明 PNG 蒙版：透明像素允许替换，黑色不透明像素保留。

后端把蒙版作为独立的 multipart `mask` 字段发送到 OpenAI-compatible `/v1/images/edits`。显式蒙版要求：

- 必须同时提供源图片；
- 必须是 PNG；
- 只允许图像请求；
- 原生 Gemini 和 Grok 图片路由当前会给出明确的不支持错误，不会悄悄退化为无蒙版编辑。

## 快捷操作

| 操作 | 快捷键 |
| --- | --- |
| 搜索并添加节点 | `Ctrl/Cmd + K`，或双击画布 |
| 运行星图 | `Ctrl/Cmd + Enter` |
| 撤销 / 重做 | `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` |
| 复制选中节点 | `Ctrl/Cmd + D` |
| 适应画布 | `F` |
| 停止运行 | `Esc` |

命令面板支持方向键选择、Enter 添加和 Escape 关闭。左键拖动画布框选；中键或右键拖动画布平移。

## 参考研究

参考仓库只保存在工作区外层 `research`，不会进入产品包：

- ComfyUI `6f7cd7fceaaf60d2669b554936394a7412c6fde5`
- ComfyUI frontend `24d6c309d187fd5ef7af55cdfb7d970b06f013fc`
- Image Studio `13c3ebeaaed8d56ff8fb3680880f3cf7ba70aec5`

研究采用但重新设计的部分：

- ComfyUI 的类型化节点、子图/蓝图边界、参数保留和工作流复用；
- Image Studio 的画布、标注、蒙版、扩图、历史参数复用与预设思路；
- 社区高频反馈中的菜单层级过深、悬浮菜单遮挡、历史不可追踪、蒙版编辑脆弱和子图边界不完整。

星图因此把高频动作固定在画布工具栏，把蓝图作为一等对象，把蒙版做成真实后端契约，并在常见窄屏宽度默认让画布优先。
