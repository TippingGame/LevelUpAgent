# v1.4.83：钉钉后台机器人与干净的创作提示词

- 钉钉桌面机器人使用窗口定向收发；其他应用中的键鼠操作不再使扫描与发送等待空闲。真实客户端干扰测试通过，完整证据与边界见 DINGTALK_BACKGROUND_1.4.83.md。
- 自动机器人支持独立身份、模型、知识、人物记忆、白名单路由、持久化收发记录与人工接管；官方平台 SDK 和实验性 OneBot 通道维持各自权限边界。
- 一键破甲只增强会话提示词，创作空间保留皮肤，生成不再插入破甲提示词；删除一键破甲控制台。
- 生图客户端保留 GPT Image 2 / 2.5 原有 size / quality 合约。image2pro 的 aspect_ratio / resolution 转换只位于独立 LevelUpAPI 项目的精确上游适配器，其他上游不受影响。
- 应用版本 1.4.83；音频及 3D 独立资源复用。

## 本地验证

- 冻结依赖安装、307 项前端测试、生产构建、Rust 格式检查通过。
- Rust 全量 586 项通过（5 项忽略）；机器人 Clippy 修正后专项 20 项通过，全目标 Clippy 零警告。
- 机器人 Python 全量 79 项通过；补充扫描并发检查后桌面专项 70 项通过。3D 21 项（3 跳过）、音频 9 项（2 跳过）通过。
- 隔离 Tauri 机器人验收：15 次本地模拟模型调用、13 次模拟平台发送；覆盖独立身份、知识 ACL、去重、暂停、未知发送、重启、四种外观、真实钉钉只读校准与 Python 环境复用。
- 隔离 Tauri 创作验收：GPT Image 2 / 2.5 × 浅色/深色 × 破甲开/关的 8 次本地 HTTP 生成，全部保留干净原始提示词；皮肤、预览、720px 布局与重载通过。
- 真实钉钉后台发送在 169 次键盘字符和 169 次鼠标移动期间成功，前台不变，草稿清空。附加实时接收窗口没有新消息，未记为真实接收或模型端到端验证。

后台支持已打开、非最小化且 Windows 解锁的钉钉；切回钉钉暂停避免人工编辑冲突，回复换行显示为空格。macOS/Linux 不提供 Windows 钉钉桌面接入。跨平台构建、资产与签名验证将在正式发布后记录。
