# v1.5.90：视频模型动态分辨率

- 桌面视频页按完整模型 ID 动态生成清晰度选项，与在线 Agent 一致。修复 `无限制-MiniMax-H3-1K` 被截成基础型号、1K 选项缺失的问题。
- 切换 1080P、1K、2K 等型号时同步更新可选项、显示值和提交值；星图继续共用分辨率规则。
- 移除客户端“显式分辨率必须与模型名后缀相同”的硬拦截，省略参数时仍使用后缀默认值。具体上游的真实输出能力仍由供应商决定。
- LevelUpAPI 配套源码同样移除了后缀硬拦截；Image2pro H3 使用模型目录中的实际输出档位处理旧参数，并在预留费用前核对实际档位售价。该服务端变更需独立部署。

## 验证

- 项目检查 309 项、Rust 媒体测试 56 项、生产前端构建通过。
- 浏览器和隔离原生 Tauri WebView 分别验证 24 次模型切换及提交，覆盖 6 种型号、浅色／深色与 Armor 开关、720px 窗口及刷新恢复；1K 正常显示且与提交值一致。
- LevelUpAPI 媒体服务与处理器回归通过，在线 Agent 及价格界面 52 项测试通过；测试验证 H3 旧参数按实际 1K 档位预留费用，未配置该档位价格时不会创建付费任务。
- 本轮使用本地模拟接口核对请求，没有调用付费视频生成。
