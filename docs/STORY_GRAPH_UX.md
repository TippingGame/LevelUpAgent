# 剧情图交互设计

## 目标

剧情图既要让作者快速捕捉和重排想法，也要在分支变复杂后仍然看得清、找得到、改得动。画布操作不能绕过现有的剧情语义：默认后继、选项、条件、效果、路径检查、试玩和 Yarn 导出必须始终使用同一份项目数据。

## 调研信号

- [React Flow](https://reactflow.dev/learn) 将节点拖动、端口连接、缩放、平移、选择、小地图、键盘与无障碍作为节点编辑器的基础能力。LevelUpAgent 使用它承载画布交互，但不采用它的数据格式作为项目存储格式。
- [Unity 开发者论坛对 Arcweave 早期方案的讨论](https://discussions.unity.com/t/we-are-building-a-web-tool-for-game-and-story-design-looking-for-feedback/709166) 反复强调：快速编辑、能同时看到全局和聚焦局部、连线标签、多选复制、从粗糙想法快速整理，以及离线可靠性。
- Google 检索到的 Reddit /r/gamedesign、/r/gamedev 和 /r/twinegames 讨论集中在三类痛点：大型分支图容易形成难以追踪的“意大利面连线”；视觉编辑器会打断连续写作；基础工具经常缺少可靠撤销、搜索、自动整理和快捷连线。Reddit 页面在当前网络环境下要求登录，因此这里只把搜索摘要作为辅助信号，而不把它当作唯一依据。
- Articy、Arcweave、Twine、Ink 和 Yarn Spinner 的市场分化表明，理想方案不是一味增加面板，而是把“文本优先写作”和“可视化结构检查”组合起来。LevelUpAgent 保留右侧详细编辑器和 Yarn 导出，同时让画布承担结构操作。

## 已实现的交互

- 自由拖动节点；按住 `Shift` 在画布框选，`Ctrl` 追加多选，也可开启显式“框选模式”直接拖动空白区域批量选择。
- 每个节点左侧是输入端口；右侧分别提供默认路径、现有选项和“新分支”端口。端口具有更大的鼠标命中热区和无障碍标签，缩放后仍容易抓取。
- 从端口拖到目标节点即可连接；已有连线可以拖动端点重新连接，选中后按 `Delete` 可断开。删除选项连线只清空目标，不会丢失选项文字、条件或效果。
- 把连线拖到空白画布，会在落点创建左侧导航当前选中的节点类型并自动连接；双击空白画布可直接新建节点。
- 滚轮缩放、拖动画布、缩放控制、小地图、显示全部节点和可选网格吸附。
- 自动整理按开始节点和路径层级从左到右排列；不可达节点放入独立区域，便于发现遗漏。
- 画布级撤销/重做，覆盖移动、连接、断开、重连、创建、复制、删除和自动整理；快捷键为 `Ctrl+Z`、`Ctrl+Y` / `Ctrl+Shift+Z`。
- 多选后可整体拖动、复制或删除；删除节点会修复所有入边，并可撤销。
- 左侧剧情节点支持搜索标题、正文、节点类型和选项文字；从列表选择节点时画布会自动定位。
- 连线直接显示“继续”“默认路径”或选项文字；有条件的分支使用虚线，节点上的检查问题会显示数量徽标。
- 右侧检查器可收起，提供专注画布模式；窄窗口会默认收起并以浮层形式打开，600px 及以下的节点导航改为抽屉，避免画布被侧栏挤没。

## 数据与兼容性

- 项目仍然持久化 `StoryNode.nextNodeId` 和 `StoryChoice.targetNodeId`，旧项目无需迁移。
- 画布边是由剧情数据派生的视图，不会产生第二份容易失配的连线数据。
- 节点坐标范围放宽到正负 100,000，允许真正的可平移无限画布；导入时仍会限制异常数值。
- 直接新建分支会生成可编辑的选项，默认名称为“前往 {目标节点}”。

## 后续可验证方向

- 大型项目的可折叠分组、子图与多画板。
- 试玩路径覆盖率、未走过分支高亮和变量状态热力图。
- 命令面板与纯键盘快速建图，让连续写作时不必频繁移向鼠标。
- 在画布内直接编辑短标题和选项，详细正文仍留在检查器中。
- 以快照为基础的剧情结构差异视图，而不只是整项目恢复。
