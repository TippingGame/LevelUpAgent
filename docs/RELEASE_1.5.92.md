# v1.5.92：桌面自动回复截图校准重构

- 新建账号默认选中钉钉桌面版，并支持选择其他桌面应用。
- 支持自动截取目标窗口、上传界面截图、裁剪完整窗口及放大拖框；手动指定消息入口、会话列表、标题、正文、输入栏和发送按钮，运行时不再套用固定布局或猜测控件标签。
- 红点触发已绑定会话的未读检查，点击清除红点后继续等待正文稳定；当前打开会话的新消息也能处理。
- 标题包含登记的人名或群名即可匹配，支持部门、人数与状态后缀。重叠规则优先较长名称，暂停规则与同名歧义继续受保护。
- 默认前台兼容模式，保留可选的旧版钉钉后台模式；输入前检查草稿与焦点，发送前核对标题和文字，发送结果不明确时不自动重发。
- 校准、未读状态和去重记录持久化；旧账号可重新截图框选升级。窗口移动不影响校准，尺寸或内部布局变化后需重新框选。
- 音频和 3D 独立资源版本不变，继续复用已有资源。

## 使用与验证

使用流程与适用范围见 [桌面截图校准说明](DESKTOP_CALIBRATION.md)。通用桌面模式面向具有可见未读标记与可读文字气泡的 Windows 应用，不保证所有应用的绘制和输入方式兼容，图片、语音和附件不自动理解。

本次功能验证包括 127 项桌面 Python 回归、21 项 Rust 聊天模块测试，以及浅色／深色、Armor 开关四种外观下的 720px 截图框选、上传裁剪和缩放。独立 Tauri 实例完成默认选项、非法校准拒绝、配置保存、编辑及关闭重启验证，未向真实联系人发送测试消息。

发布前完整项目检查 311 项、Rust 全量测试 593 项通过（5 项忽略），格式检查、全目标 Clippy 零警告和生产前端构建通过。聊天网关 Python 137 项通过；3D 资源 21 项（3 项平台跳过）、音频 9 项（2 项环境跳过）通过。发布结果及资产校验记录将在完成后补充。
