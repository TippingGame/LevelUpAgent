# v1.3.80：工作台依赖移除与图片输入性能优化

## 变化

- 音频与 3D 工作台在「环境与下载」新增「移除已安装依赖」，在线安装和离线导入都可清理。音频按所选引擎，3D 按当前平台与资源版本移除运行环境、模型及安装缓存。
- 移除前显示范围并要求确认；生成、排队或安装期间阻止移除，文件占用时可重试。保留作品、历史、参考文件与原始离线包。Windows 不清理旧 WSL / Linux 资源。
- 音频最后一个运行环境移除后，重启仍可查看作品历史、试听及导出 WAV。再次生成或进行依赖 Python 的操作前重新安装。
- 图片历史使用稳定事件分发和列表缓存，避免输入提示词时重复渲染已加载卡片；增加图片延迟加载、异步解码与屏幕外绘制优化。
- 应用版本升级至 1.3.80；音频、Windows / Linux 3D 独立资源版本不变，继续复用，无需重复下载或上传模型。

## 验证

已在隔离 Windows Tauri 实例验证三个音频引擎分别移除、历史 / 试听 / 导出保留及重启，3D 离线导入 → 移除 → 再导入，资源占用拒绝与重试。浅深色 × 装甲开关、720×560 窗口均通过。

1920×1080 开发版对比，加载 240 条历史并输入 31 个字符，React 渲染总耗时由 1,370.8 ms 降至 132.6 ms；真实最大化 Tauri 窗口加载 240 张本地 JPEG，四种外观下输入未记录到超过 50 ms 的主线程长任务。检查了历史翻页、图片预览 / 导航、复制提示词、连续复用、编辑和删除。数字对应固定测试环境，不代表所有设备或输入法的延迟保证。
