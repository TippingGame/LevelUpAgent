# v1.5.95：桌面自动回复发送队列与进度修复

- 修复已生成的回复一直等待发送：桌面控制器准备完成后，发送队列独立于未读消息观察状态运行，无红点、当前聊天未绑定或暂时没有可读正文不再阻塞已有回复。
- 输入前因人工操作或草稿暂缓时，保留同一条回复，至少等待 5 秒后重新检查，不重复生成；输入后异常和发送结果不明仍禁止自动重发。
- 修正后台点击使钉钉自行激活后，将其他应用之前的键鼠操作误判为正在操作钉钉的问题；新的人工输入仍会中止操作。
- 收发记录显示具体等待原因和定位会话、检查草稿、写入、核对发送结果等进度。连续 45 秒没有新进度或单次尝试总计达到 120 秒时停止控制器，将未确认的发送转为待确认。
- 保留已有截图、框选区域、聊天路由和执行模式；音频及 3D 独立资源继续复用。

## 升级与验证范围

退出旧版后安装 1.5.95，再启动应用。已有账号和校准沿用；如果仍等待发送，请查看收发记录里的具体原因，核对目标窗口未最小化、输入栏无草稿及框选区域正确。

旧版已经进入“送达待确认”的记录不会自动重发。请先在钉钉核对，再标记已送达或放弃；避免手动发送重复回复。后台窗口消息模式可能使钉钉自行激活，不保证完全不抢焦点。

问题由另一台电脑的 1.5.94 用户报告。本次验证包括调度和协议回归、合成输入事件、浏览器四种外观及隔离 Tauri 原生界面；未在问题电脑复测，也未向真实联系人发送新消息，不把这些检查描述为真实平台完整收发已验证。
