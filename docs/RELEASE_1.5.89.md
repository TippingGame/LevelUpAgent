# v1.5.89：钉钉聊天列表标记识别

- 修复列表标题与橙色 `@好友` 标记被 OCR 合并后无法找到聊天的问题。必须先匹配完整名称及已知标记，再只移除实际橙色标记像素，独立高置信度识别完整名称；不接受任意前缀或后缀匹配。深色文字组成的同名后缀、相近名称、重复聊天仍被拒绝或视为歧义。
- 当前聊天标题首帧未匹配时，先重新截图读取一次，避免瞬间识别失败立即触发聊天切换。点击聊天后仍须重新核对完整标题。
- 后台切换失败时提示暂停连接、选择前台兼容模式并保存重连；列表查找失败提示核对绑定名称与区域，不再只要求置顶。
- 继续保留 1.5.88 的新版编辑器、草稿保护、消息方向及历史基线修复。音频和 3D 资源版本不变。

## 配置

出现「后台切换聊天后的标题核对失败」表示仍在后台模式。编辑账号 → 暂停连接 → 选择「前台兼容模式 · 新版钉钉」→ 自动识别区域并预览 → 保存并连接。仅断开重连不会改变发送模式。

历史基线提示是正常启动阶段；进入监听后再从对端发新文本。钉钉保持打开且不最小化，前台兼容发送前须让键鼠空闲 5 秒。
