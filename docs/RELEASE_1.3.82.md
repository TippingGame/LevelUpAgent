# v1.3.82：模型连接与桌宠名字栏修复

## 变化

- 模型连接保留图片、视频、音频等非文字模型 ID；检测模型保留已选项，只有媒体模型的分组也能选择和保存。
- 余额查询跟随设置中选中的连接，与文字会话模型独立；保存和重启后保留选择，快速切换或移除密钥后忽略过期查询结果。
- 删除连接后选中列表中的上一项；删除第一项则选下一项，保留最后一个连接。切换时清理原连接的模型目录、密钥输入与诊断状态。
- 新建连接和首次初始化连接默认不勾选“允许作为文字备用连接”，已保存的连接保留原设置。
- 摇光残影桌宠名字栏仅显示名字、等级与经验进度，不再在等级后追加行为状态；思考气泡仍显示状态详情。
- 应用版本升级至 1.3.82，音频和 3D 独立资源版本不变。

## 验证与发布

- 冻结锁文件安装、TypeScript／外观／更新端点检查、309 项前端测试与生产构建通过。
- Rust 格式检查、565 项测试（另有 5 项忽略）与全目标 Clippy 零警告通过。
- 3D Python：21 项（3 项平台相关跳过）；音频 Python：9 项（2 项平台相关跳过）。
- 浏览器完整应用回归覆盖浅色／深色 × Armor Mode 开／关、720 px 视口、媒体模型保存、余额与诊断、重载、快速切换旧响应、删除首项／中间项／末项、最后一项保护、保存失败和移除密钥。
- 隔离 Windows 原生应用使用独立 identifier、合成凭据和本地 HTTP 服务，验证真实 Tauri IPC／系统凭据读取、无文字模型连接的余额、媒体模型保存、删除后上一项与新连接备用默认值；四种外观、720 px WebView 视口及桌宠名字栏通过。等级后不含状态，长名字不挤压等级，名字栏高度 28 px、进度条至少 38 px。
