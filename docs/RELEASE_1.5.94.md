# v1.5.94：钉钉未读导航与新版桌面收发修复

- 修复消息入口框住整列菜单时误点 OA 审批的问题；仅定位唯一消息入口，排除其他菜单红点，重复无效点击会停止并给出原因。
- 改进未读会话识别：排除消息预览中的姓名和重复数字，修正头像影响红点识别的问题，保留真实同名会话的歧义保护。
- 新版钉钉的点击和文字输入定位到实际列表、编辑器子窗口，解决外层窗口收到操作却不响应的问题。
- 后台读取不再被其他应用中的人工操作阻塞；用户正在钉钉操作时，暂缓点击和发送。正文加载过程中保留待处理未读消息，修复气泡边界导致收到消息漏读的问题。
- 桌面设置直接显示执行模式、消息入口诊断和识别出的会话名称，帮助检查框选区域。
- 保留截图及区域持久化、名称包含匹配、草稿保护、发送前标题核验，以及发送结果不明不重试。
- 音频和 3D 独立资源继续复用。

## 使用与验证范围

升级后暂停桌面连接，在账号设置核对六个区域，点击“检查实时识别”，确认消息入口和会话名称正确后保存、重连。消息入口应只包含消息按钮，避免框住整列菜单；窗口尺寸或内部布局变化后需重新校准。

新建钉钉账号默认后台窗口消息模式，已有账号保留已保存模式。该模式不移动鼠标，但钉钉可能在切换会话时自行激活窗口，**不保证完全不抢焦点**。本机 9.0.4.261021001 上已在用户授权会话实测自动打开聊天、读取收到消息并发送一条固定测试回复；这不包含远程模型生成。其他无焦点方案未同时通过导航与焦点验证，未接入。

详细行为与实测边界见 [桌面截图校准说明](DESKTOP_CALIBRATION.md)。私人截图、原始聊天记录和测试配置不随源码或安装包发布。
