## 已确认的差异

- 新包应用外壳提交 `63e628e`，底层为 ComfyUI v0.37.2、提交 `830232b856045ca2892833212d7771078a13edd5`。ComfyUI 工作区仅删除了输出目录占位文件；原始参考目录不修改。
- 模型为 `Comfy-Org/YuE2` 格式的 `yue2_3b_int8_convrot.safetensors`，约 3.96 GB；现有正式资源是原版 `m-a-p/YuE2-3B` 加独立 VAE，使用 `yue2-infer`。加载接口和权重布局不同，不能将新文件直接放进旧资源包。
- 新包额外包含 SheetSage2 BF16 音频转 ABC 模型及 torchaudio HDEMUCS 分离权重。参考音频改编通过旋律 ABC 条件实现；其纯音乐工作流是生成、去人声、提取旋律后重生成并再次去人声，并非只写“无歌词”提示。
- 新包内运行环境为 Python 3.13、PyTorch 2.12/CUDA 13.0，现有正式 YuE2 为 Python 3.12、PyTorch 2.10/CUDA 12.8。需验证兼容依赖后决定新资源要求，不把整合包发布日期当作官方重新训练模型的版本号。

## 最终实现与资源

- 正式程序沿用简单的纯音乐／带歌词切换；仅 YuE2 增加折叠的参考音频。参考经独立 runtime 的 PyAV 解码到管理目录，最大 256 MiB、1–600 秒，生成请求仅接收 UUID。支持原文件保留、草稿／作品参数复用和重新导入。
- 官方原版 `m-a-p/YuE2-3B` 与 `YuE2-Vae` 的最新 revision 仍分别是 `8f24312f187763b9854adeec87e437e2b03bbff1`、`152733a19ad43aa67e367f9b5503ef8075bb5126`。不能把整合包日期解释成重新训练模型的发布日期。
- 新模型来自 `Comfy-Org/YuE2`，固定 revision `2f76ca75e6ee094169de899cc7fc99d6887e2196`。INT8 checkpoint 3,960,938,800 bytes，含 VAE；SheetSage2 1,386,868,122 bytes。两者与官方 HF LFS SHA256 一致。HDEMUCS 334,697,255 bytes，已从官方 torchaudio 地址独立下载，与本地权重 SHA256 一致。
- 新独立资源版本 `2026.10.11-yue2-int8`、目标 `windows-x64-cu130`。运行环境使用官方 Python 3.13.12、匹配的 torch/torchaudio 2.11.0 与 torchvision 0.26.0；没有沿用参考包 torch 2.12 / torchaudio 2.11 的混用组合。
- CUDA 12.8 的 INT8 8 秒探针确实能运行，但同机耗时 56.31 秒；参考 CUDA 13 探针为 21.68 秒。最终匹配的 2.11/CUDA 13 环境再通过下表完整生产桥接测试。该探针对比不是跨硬件性能保证。
- runtime 共 3 分卷、2,200,160,805 下载 bytes、3,483,213,945 安装 bytes；models 共 5 分卷、4,854,582,118 下载 bytes、5,682,570,864 安装 bytes。合计下载约 6.57 GiB，安装约 8.54 GiB，另有 JSON 清单。主安装包只包含 10 个小型音频控制文件。
- ComfyUI 完整对应 GPL-3.0 源码放在 runtime 的 `comfy-source/`，仅调用推理库，不启动服务或加载 custom nodes。YuE2、SheetSage2 保留 CC-BY-NC-4.0 许可与归属，HDEMUCS 保留 MIT 许可；未复制无独立许可的外层 WebUI。
