# Agent 工作流

适用：`1.0.56` 之后的当前工作树，2026-09-18。

## 会话与草稿

打开项目后新建会话，或使用应用分配的临时工作区。项目支持隐藏、展开，会话支持置顶、重命名、删除、分支、导入与导出。

桌面启动只读取会话摘要与所选会话正文。“加载更多会话”继续读取更早记录；搜索覆盖已持久化的标题、工作区和用户/助手正文，不受当前加载页限制。工具输出和内部续跑消息不进入正文检索。查询按字面匹配，不支持正则或语义检索。

聊天 `Ctrl/Cmd+K` 打开会话与命令面板，方向键选择、Enter 执行、Escape 关闭。星图的同一快捷键保留节点搜索含义。面板与侧栏共享查询；侧栏搜索未展开时，关闭面板会解除侧栏筛选。

每个会话保存自己的原始输入文本和附件引用，250 ms 合并写入；切换、页面隐藏和桌面关闭会触发保存。桌面使用 SQLite，浏览器预览使用 localStorage。失败保留内存内容并显示重试入口，桌面关闭前草稿刷新失败会保持窗口打开。正常关闭还等待合并的会话消息保存结束。附件字节仍在托管目录，草稿不复制二进制。强制结束进程或突然断电前尚未刷新到磁盘的内容无法保证恢复。

已发送内容从原会话草稿中移除；发送等待期间新增的文字和附件保留。异步粘贴/拖入的附件回到发起导入的会话。删除会话清除其草稿，迟到的加载结果不会重建已删除会话。

长会话初始挂载最近 40 个用户/助手块。“加载更早的消息”每次展开 40 个并保留滚动位置。完整活动会话仍加载在内存中，这不是消息数据库分页或完整虚拟列表。

## 模式与权限

模式与权限是两层限制，主机先检查模式，再裁决权限。

| 模式 | 行为 |
| --- | --- |
| Chat | 模型问答，不提供工具 |
| Plan | 只读工具和规划，拒绝写文件、命令及外部副作用 |
| Agent | 执行单次任务；非 Goal Harness 有 64 回合保护 |
| Goal | 持续推进到完成、暂停、取消、阻塞或终止错误；完成先进入审计 |

| 权限 | 文件范围 | 自动执行 |
| --- | --- | --- |
| request | 工作区内 | 只读和受限本地状态工具；其余询问 |
| agent（新安装默认） | 工作区内 | 只读、文件写入/编辑、委派，以及通过命令风险检查的命令 |
| full | 允许工作区外 | 已分类工具；未知凭据敏感工具仍需批准 |

模式限制在 full 下仍然有效。命令检查是启发式风险门禁，既不是 shell 解析器，也不是 OS 沙箱。删除、外部工具、媒体付费调用、补丁应用在 request/agent 下通常需要审批。用户主动点击的 Git 回滚和 CLI 写回另有预览确认令牌。

## 项目约定与工具

Agent、Plan 和 Goal 每轮读取所选工作区根目录的 `AGENTS.override.md`，为空或不存在时读取 `AGENTS.md`。文件须为 UTF-8 普通文件，最多 32 KiB；超限、不可读或符号链接会报告错误。来源路径、内容指纹和字节数记入 Harness 事件。项目约定不能授权工具或覆盖用户当前要求。

当前不向父目录搜索，也不按编辑文件继承子目录指令。需要深层约定时，把必要规则放在所选根文件，或要求 Agent 显式阅读。问答、写作补全、主题生成和专门孵化链路不自动载入项目文件。

长文件可传 `start_line`、`end_line`、`max_lines`、`line_numbers`。区间从 1 开始，默认 200 行，最多 2,000 行；`end_line` 与 `max_lines` 同时指定时取更小范围。字符预算触发时按实际行号提示续读；单行过长会明确提示未读完。完全不传范围参数时保持原读取行为。

命令、浏览器、Skills、MCP 与后台服务见 [工具文档](SKILLS_AND_TOOLS.md)。

## 运行中输入与恢复

运行中普通输入加入 follow-up 队列，当前任务结束后逐项处理。`/steer 内容` 引导当前任务，Provider 等待可中断，在途工具先完成。`/follow-up 内容`、`/next-turn 内容`保留显式意图。运行队列只支持文本。

重启后：

- 活跃 Goal 转为暂停，用户明确恢复后继续。
- 运行中 operation 转为 interrupted，旧 Provider 请求标记失败。
- 等待审批保留，审批令牌重新签发；结果不明工具需要人工确认已执行、未执行或取消。
- 中断 operation 尚未注入的队列项当前会取消，正文仍在账本但没有恢复到输入框的入口，需要重新提交。这是当前恢复能力的缺口。
- 后台进程和浏览器会话不会自动恢复；媒体任务可凭原远端任务 ID 继续查询和下载。

会话分支生成新的消息 ID，不复制工作区或创建 Git 分支。子 Agent 临时隔离 worktree 是另一项能力。

## 验证与数据

SQLite 包含完整会话、草稿和工具账本。Provider 请求日志不含正文，不代表整个数据库没有敏感内容。公开导出前应检查任务内容、路径和自行粘贴的秘密。

```sh
pnpm check
cargo test --manifest-path src-tauri/Cargo.toml
pnpm bench:persistence
```

浏览器交互：启动 `pnpm dev --host 127.0.0.1 --port 1430`，在可解析 Playwright 的环境运行 `node scripts/verify-workbench.mjs`。可用 `LEVELUP_PLAYWRIGHT_MODULE` 指定其 `index.mjs` 绝对路径。脚本使用独立浏览器上下文和模拟会话，不访问桌面生产数据库。
