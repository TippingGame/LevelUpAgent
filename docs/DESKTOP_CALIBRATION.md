# 桌面应用截图校准（2026-11-06）

新建账号默认选择钉钉桌面接入。进入桌面设置后，也可以选择「其他桌面应用」，按可见窗口和所属进程绑定。桌面通道的内部平台 ID 仍为 `dingtalk_desktop`，以兼容已有账号、路由和历史数据。

## 使用流程

1. 选择应用，检测并选择目标窗口。钉钉只列出已核验的钉钉进程；其他应用列出可见的主窗口。
2. 点击「自动截图」，或者上传 PNG、JPEG、WebP 截图。上传整屏图片时先框出完整应用窗口，包含窗口边缘；也可以确认图片已经是完整窗口。
3. 拖动框选六个区域：消息栏/红点入口、会话列表、标题、聊天正文、输入栏、发送按钮。可放大截图、清除单个框或输入 0–1 相对坐标。输入栏应清空草稿，正文应包含左右两侧气泡，红点入口应排除其他通知入口。
4. 点击「检查实时识别」。核对标题、未读红点、正文方向与草稿状态，保存账号。
5. 在聊天路由登记人名或群名，并绑定机器人。标题包含名称即匹配，无需附带部门、群人数或状态。群聊仅 @ 模式需填写自己的显示名，也可为单个群选择全部新文本。

截图只用于本地校准，不作为模型输入。保存账号时，截图图片、窗口身份、截图尺寸及全部相对区域坐标一并保存到本机；重新编辑或重启应用后会恢复图片和框选。旧版未保存的截图无法补回，需要重新获取一次，尺寸相同会保留已有框选。窗口移动无需重新校准；改变窗口大小、侧栏宽度或内部布局后，需要重新截图框选。上传图片的尺寸与当前窗口必须一致，不会把桌面坐标当成窗口坐标使用。

已有桌面连接时，平台账号页直接编辑原账号，包括已断开的连接；多个联系人在「聊天路由」中添加，不重复创建桌面账号。添加其他平台可使用「添加其他平台账号」。

## 运行行为

- 配置版本 2 使用手动区域，运行时不猜控件标签、不替换区域。旧版配置仍可读取，重新截图校准后升级；不自动修改已保存账号。
- 观察红点入口和会话列表。入口有红点且列表未出现已登记未读会话时，点击入口后再识别列表。只进入可见、已登记、可唯一匹配的未读会话。
- 点击后保留未读状态，等待两次相同正文观察，避免红点清除或局部渲染丢失消息。没有红点时仍观察当前已绑定会话，接收窗口已经打开时的新消息。
- 首次进入未读会话或历史视口失去重叠时，仅处理最新一条可读的收到消息；已有连续基线时处理可核验的新增消息。未读数字不被当作可靠的历史消息数量。重启保留去重历史；不会批量回复旧消息。
- 包含匹配优先最长名称。暂停的更长名称仍排除较短名称，多个同名行或等长规则歧义暂停处理。OCR 无法区分同名用户，请使用能区分的名称并检查预览。
- 新建钉钉配置默认后台模式，不抢焦点，用户操作钉钉时暂停。手动校准版本直接使用框选输入区，不强制查找旧版输入控件标签；消息入口位于聊天子窗口外时，点击定向到同进程的导航窗口。
- 其他桌面应用默认前台兼容模式，切换和发送前等待键鼠空闲；钉钉也可手动选择此模式。已有账号保留已保存模式，可在「收发设置与精确坐标」中切换并保存。输入前检查草稿，发送前再次核对标题和文字，点击发送框中心。已有草稿不覆盖，发送结果不明不自动重发。

## 适用范围与限制

适用于 Windows 上具有可截图窗口、可见红点、名称和文字聊天气泡的应用。正文仍采用本地 OCR 和气泡形状识别，支持范围取决于应用绘制和输入实现；这不保证任何桌面软件都可接入。图片、语音、附件、复杂富文本及屏幕外会话不自动理解或发现。空输入框的提示文字可配置，有提示时需要可读的空 UIA 值辅助核验。没有可核验焦点或草稿的应用会停止输入。

本地发出气泡是发送核验依据，不代表服务器或对方已收到。运行需窗口未最小化、Windows 解锁。每次仅保存一个桌面控制器账号，防止同时争用输入。
