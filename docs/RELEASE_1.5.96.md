# v1.5.96：桌面会话切换与发送优先处理修复

- 切换会话不再检查当前输入栏是否有草稿；前台兼容、后台模式及框选区域导航均允许直接切换，不修改草稿。进入目标会话后，实际写入回复前仍检查输入栏，发送前仍核对标题和回复文字。
- 优先检查未读会话；没有可处理红点时，每隔至少 15 秒轮询一个可见且唯一匹配的绑定会话，不再一直停在未绑定聊天。首次检查建立历史基线，避免把已有消息当作新消息回复。
- 收到发送请求立即报告进度，在当前截图或 OCR 调用结束后的检查点让出观察流程，优先处理待发回复；桌面操作仍串行执行，不并发点击或输入。
- 保留点击后已清除红点的读取意图，避免观察被发送打断后漏掉新消息；暂停路由、同名歧义、失败冷却和发送结果不明不重试保护继续有效。
- 已有账号、截图、框选区域、聊天路由和执行模式沿用；音频及 3D 独立资源继续复用。

## 升级与验证范围

退出旧版后安装 1.5.96，再启动应用。目标会话需在框选的会话列表中可见，窗口保持打开且未最小化。已绑定名称仍采用包含匹配，真实同名或无法唯一定位的会话不会盲目点击。窗口尺寸或内部布局变化后需重新校准。

有草稿不会阻止切换，但目标会话中有草稿时不会覆盖并自动发送。旧版已经进入“送达待确认”的记录不会自动重发，请先在聊天软件核对再标记。后台模式仍可能使钉钉自行激活，不保证完全不抢焦点。

本次回归覆盖草稿导航、无红点检查、历史基线、多会话轮询、暂停与重名排除、未读状态保留和真实子进程协议中的发送优先处理。本机窗口工具两次返回归属错误，未完成真实钉钉导航验证，也未向联系人发送新消息；另一台问题电脑需要升级后复测。

详细行为见 [桌面截图校准说明](DESKTOP_CALIBRATION.md)。本地证据位于 `artifacts/desktop-navigation-review/` 和 `artifacts/release-1.5.96/`。
