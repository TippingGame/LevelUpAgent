# v1.5.88：新版钉钉读取与前台兼容发送

- 兼容新版钉钉原生输入框、发送按钮及聊天列表，修复空输入框占位文字和光标被误判为草稿、收到的消息气泡被过滤的问题。
- 默认未校准区域自动使用原生控件定位；短暂空 OCR 帧保留历史指纹，减少恢复后新消息被吞作历史基线。
- 新消息使消息列表上移、顶部旧气泡 OCR 变化时，使用其后的至少两条不同且完全匹配的旧消息确认追加关系；过滤已知历史续段，避免吞掉新消息或翻阅历史时补发回复。
- 新增可选「前台兼容模式 · 新版钉钉」：适用于能读取消息但后台输入无效的客户端。发送时激活钉钉，等待键鼠空闲 5 秒；人工操作、已有草稿、标题变化或窗口移动会阻止发送。旧账号默认仍为后台模式。
- 监听状态显示识别到的总消息数、收到数量和触发条件；空识别结果提示检查区域，不再仅显示在线。
- 版本递增到 1.5.88，音频和 3D 独立资源继续复用。

## 使用

在「自动答复机器人 → 账号」中编辑钉钉账号，暂停连接，选择「前台兼容模式 · 新版钉钉」，自动识别区域并预览，保存后连接。钉钉保持打开且不最小化；基线建立后由对端发新文本。发送期间让键鼠空闲。
