# v1.5.86：钉钉窗口识别与模型连接体验改进

- 钉钉窗口进程路径读取失败时，使用 Windows 进程快照按 PID 和准确程序名备用识别；修复最小化窗口被尺寸过滤漏掉的问题。
- 自动答复机器人直接显示检测到的窗口、尺寸和最小化状态；空列表提供原因，连接运行中的校准锁定说明更清晰，重试会清除过期结果。
- 模型连接刷新目录后，根据服务地址和模型信息自动匹配一次协议，仍可手动修改；刷新期间编辑的内容不会被迟到结果覆盖。
- 协议卡片增加高对比边框、底色和“已选中”勾选标记，增强深色模式及 Armor Mode 的辨识度；模型列表同步增强选中效果。
- 识别 Nano Banana 图片模型别名并保留原生路由。
- 应用版本为 1.5.86；音频及 3D 独立资源版本保持不变，继续复用。

## 验证

- 冻结依赖安装、309 项前端测试、外观检查、发布配置检查及生产前端构建通过。
- Rust 格式检查、592 项测试（5 项忽略）及全目标 Clippy 零警告通过。
- 机器人 Python 95 项通过；3D Python 21 项（3 项平台相关跳过）、音频 Python 9 项（2 项需要便携运行环境而跳过）通过。
- 模型连接和钉钉设置覆盖浅色／深色 × Armor Mode 开关、720px 布局与隔离原生 Tauri 检测链路。
- 5 份音频与 3D 资源清单和 48 个分卷公开可用，清单与 GitHub digest 一致。
- 当前合并机器未运行钉钉；未验证真实钉钉消息收发。进程查询失败及最小化分支有模拟回归，不能视为真实客户端收发验收。

Windows x64 提供 NSIS / MSI 与 updater 签名；macOS Apple Silicon / Intel 提供 ad-hoc 签名 DMG（未公证）；Linux x64 提供 AppImage / DEB / RPM。自动更新清单仅覆盖 Windows。
