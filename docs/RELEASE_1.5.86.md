# v1.5.86：钉钉窗口识别与模型连接体验改进

- 钉钉窗口进程路径读取失败时，使用 Windows 进程快照按 PID 和准确程序名备用识别；修复最小化窗口被尺寸过滤漏掉的问题。
- 自动答复机器人直接显示检测到的窗口、尺寸和最小化状态；空列表提供原因，连接运行中的校准锁定说明更清晰，重试会清除过期结果。
- 模型连接刷新目录后，根据服务地址和模型信息自动匹配一次协议，仍可手动修改；刷新期间编辑的内容不会被迟到结果覆盖。
- 协议卡片增加高对比边框、底色和“已选中”勾选标记，增强深色模式及 Armor Mode 的辨识度；模型列表同步增强选中效果。
- 识别 Nano Banana 图片模型别名并保留原生路由。
- 应用版本为 1.5.86；音频及 3D 独立资源版本保持不变，继续复用。
