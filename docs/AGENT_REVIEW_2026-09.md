## 目标与口径

以 Codex 的日常本地开发工作流为参照，改善 LevelUpAgent 的可用性、可靠性和性能。
“80%”按明确列出的核心工作流验收，不表示模型智能、输出质量或 Codex 全产品功能的等价比例。
模型响应时间与质量仍取决于用户配置的服务。本地性能通过可重复的构建、数据库和界面基准核验。
