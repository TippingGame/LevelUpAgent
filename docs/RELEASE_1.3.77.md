# v1.3.77：思考档位与桌面残影名字条

## 变化

- 修复 GPT-6.1 Sol 只能选择“自动”的问题，支持低、中、高、超高和 Max，前后端保持一致。
- 未登记模型开放自动、关闭、极轻、低、中、高、超高和 Max，保留手动选择并发送到对应接口；已登记模型继续使用原有能力规则。实际可用档位由服务商决定，“自动”不发送额外思考参数。
- 桌面摇光残影名字条中的等级和状态保持单行，超长时使用省略号，避免状态换行撑高名字条。
- 应用版本升级到 1.3.77；音频及 3D 独立资源继续复用。

## 发布验证

本地依赖锁定安装、301 项前端测试、外观守卫、生产构建、Rust 格式检查、549 项 Rust 测试及全目标 Clippy 均通过；5 项 opt-in Rust 测试按默认规则忽略。3D Python 测试 14 项通过、2 项平台测试跳过；音频 Python 测试 7 项通过、2 项便携解码器测试跳过。

浏览器与隔离 Tauri 原生窗口均完成系统深浅色 × Armor Mode 开关四种组合验证。超长名字及中英文状态下，名字条保持 150 × 28 px，状态单行省略；主窗口切换外观和刷新通过。本次原生测试使用独立 identifier，不覆盖用户正式安装或数据。

GitHub 构建、资产与更新清单核验进行中。证据目录：`research/release-1.3.77-2026-10-13`。
