# v1.5.91：创作历史搜索与分页

- 图片、视频、语音创作历史支持关键词搜索，覆盖提示词、修订提示词、模型、连接名称和文件名；直接查询全部本地历史，不限于已加载记录。
- 增加今天、近 7 天、近 30 天和自定义日期筛选。自定义范围包含结束当天，并支持只填写开始或结束日期。
- 每页默认 20 条，可选 50、100 或全部，显示匹配总数并支持上一页／下一页。
- 增加打开本地作品目录按钮，以及清除筛选、无匹配记录、日期错误和加载失败重试提示。
- 保留生成进度与图片预览；快速切换搜索时忽略旧请求，删除末页最后一条后返回有效页。
- 音频及 3D 独立资源版本不变，继续复用已有资源。

## 验证

- 项目检查 311 项、Rust 测试 592 项通过（5 项忽略），格式检查、全目标 Clippy 零警告和生产前端构建通过。

- 前端与数据库回归覆盖中文、英文大小写、字面通配符、时间边界、分页和超过 500 条的全部历史查询。
- 浏览器验证浅色／深色及 Armor 开关四种组合、1200px／720px 窗口、三个媒体页签、搜索旧记录、快速切换、错误重试与重载。
- 隔离原生 Tauri 实例验证真实 SQLite 查询和分页。打开目录前解析实际磁盘路径，兼容打包宿主对 AppData 的 LocalCache 重定向，避免资源管理器显示“位置不可用”。原生回归默认不打开资源管理器，并在结束时关闭测试进程。
- 未调用付费媒体生成接口。macOS/Linux 安装包由原生 GitHub runner 构建，本轮未进行这两个平台的实体机交互验收。

## 平台签名

Windows 自动更新使用 Tauri updater 签名，不是 Authenticode。macOS 包为 ad-hoc 签名，未做 Apple 公证；Linux 包未做发行版签名。
