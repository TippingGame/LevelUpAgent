# LevelUpAgent 1.5.98

## 视频模型

- 视频工作台支持 CTMOAI 的 Doubao Seedance 2.0、2.5 以及对应别名。切换模型时，分辨率选项、最长时长和参考图数量随型号调整，请求保留连接配置中的完整模型 ID。
- `seedance-2.0-933` 使用自动分辨率。`minimax-h3-comic-cf-4k` 可通过兼容中转连接使用 4K。

## 下载与签名

Windows x64 提供 EXE、MSI 和应用内更新签名。macOS 按 Apple Silicon 和 Intel 分别提供 DMG，使用 ad-hoc 签名，尚未公证。Linux x64 提供 AppImage、DEB 和 RPM。
