# v1.5.93：桌面校准保存与钉钉后台模式修复

- 修复拖框生成长小数坐标时，浏览器数值步长校验阻止保存的问题。
- 截图和六个框选区域随账号一起保存，重新编辑及关闭重启后恢复。截图仅用于本机校准，不传给模型或运行时消息通道。
- 已有桌面账号（包括已断开的账号）自动进入编辑，保留账号身份及聊天路由，避免重复控制器报错；新增其他平台账号有独立入口。
- 新建钉钉配置默认后台模式，不抢焦点；其他应用默认前台兼容。已有账号保留已保存模式，可手动切换并保存。
- 后台输入使用手动框选区域，修复消息入口位于聊天子窗口外时的定向点击；继续核对窗口进程、草稿、标题和发送结果。
- 示例中的真实姓名替换为“测试联系人”。
- 音频及 3D 独立资源继续复用。

## 升级提示

旧版没有保存的截图无法补回，需要重新获取一次；窗口尺寸相同会保留已有区域。已有钉钉账号若要使用后台模式，请暂停连接，在“收发设置与精确坐标”中切换并保存。

使用流程见 [桌面截图校准说明](DESKTOP_CALIBRATION.md)。本机钉钉 9.0.4.261021001 已通过后台截图、六区域目标定位、窗口响应、标题与空草稿只读检查，未改变前台焦点；本轮没有向联系人发送消息，不将只读检查视为实际后台发送验证。

## 验证

功能验证包含聊天网关 Python 140 项、Rust 聊天模块 21 项、四种外观下的 720px 表单提交、截图保存及重新载入。独立原生 Tauri 实例验证关闭重启后截图与全部区域恢复，重复保存仍只有一个桌面控制器。

发布前项目检查 311 项、Rust 全量测试 593 项通过（5 项忽略），格式检查、全目标 Clippy 零警告、生产前端构建及 frozen-lockfile 安装通过。3D 资源 21 项（3 项跳过）、音频 9 项（2 项跳过）通过。
