# v1.4.84：钉钉窗口检测与连接校准恢复

- 修复已启用、等待或重连中的桌面账号阻止「检测钉钉窗口」的问题。窗口枚举是只读操作，保持可用；截图和校准仍要求先暂停控制器。
- 设置页增加「暂停连接并校准」。直接停止已保存的桌面连接，不退出钉钉；未保存的备注与校准编辑保留。新表单也能恢复已有的唯一桌面账号。
- 校准锁定跟随已保存的连接状态，不再误用「保存后连接」勾选框。账号卡片的连接／断开操作立即同步当前编辑器。
- 检测到唯一窗口时，可自动替换失效的窗口标题；保存账号后保留账号 ID 和设置，避免误建重复账号。
- 应用版本为 1.4.84；图片参数、创作皮肤和后台发送策略保持现有行为，音频及 3D 独立资源继续复用。

## 使用步骤

打开钉钉并登录，保持主窗口未最小化。在自动机器人的「平台账号与连接」中编辑已有桌面账号，点击「暂停连接并校准」→「检测钉钉窗口」→「自动识别区域并预览」。核对区域后，勾选「保存后连接，并随应用启动」并保存。开启机器人并绑定准确的聊天标题后，切换到其他应用进行后台监听。
